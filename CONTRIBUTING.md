# Contributing to ClimateStudy

Thank you for helping improve ClimateStudy.

## Before opening a pull request

1. Keep changes focused and easy to review.
2. Do not add secrets, credentials, private wallet material or personal data.
3. Prefer reproducible tests and documented assumptions.
4. Keep public documentation understandable for students and non-specialist users.
5. Check third-party data and software licenses before adding a dependency or dataset.

## Pull requests

Please explain:

- what changed;
- why it changed;
- how it was tested;
- any data-provider or licensing implications;
- whether documentation needs an update.

## Good first contributions

Examples include documentation improvements, data-source notes, accessibility improvements, tests, scientific validation, visualization improvements and reproducibility fixes.
