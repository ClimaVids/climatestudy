# Code of Conduct

ClimateStudy is intended to be a welcoming and professional project for students, researchers, educators, developers and contributors from around the world.

Participants are expected to:

- communicate respectfully;
- discuss evidence, code and ideas rather than people;
- welcome constructive technical disagreement;
- avoid harassment, discrimination and personal attacks;
- protect private information and credentials.

Maintainers may remove comments, issues or contributions that violate these expectations or threaten the security or integrity of the project.
